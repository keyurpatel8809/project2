## 2 · Concept of the day (10 min, shorter today so you have time on TUF+)

### Why patterns first

Pattern problems look childish. Interviewers at banks still use them in the first 5 minutes of a live-coding round because they
expose loop control instantly: off-by-one errors, wrong bounds, and whether you can reason about nested iteration without typing.

```
 Pattern 4 (n = 4)        What each loop controls
 1                        outer loop i = 1..n   → which row
 2 2                      inner loop j = 1..i   → how many items in this row
 3 3 3                    what is printed       → i, not j
 4 4 4 4
```

### Time complexity, the only three you need this week

| Shape of the code | Big-O | Picture |
|---|---|---|
| One loop over n items | O(n) | a straight line that grows with input |
| A loop inside a loop, both over n | O(n²) | a square: n rows × n columns of work |
| Halving the input each step | O(log n) | 1,000,000 items → about 20 steps |

**Analogy:** O(n) is reading every page of a book. O(n²) is, for every page, re-reading the whole book. O(log n) is finding a
word in a dictionary by opening to the middle and discarding half each time.

### The 20-minute rule

```
 0–10 min   Attempt. Write the brute force even if it is ugly.
 10–20 min  Still stuck? Write down what you know and what you are missing. Try one more idea.
 20 min     Open the editorial. Read the APPROACH only. Close it. Code it yourself.
 later      Mark it. On Saturday you re-solve it cold.
```

Problems you solved after reading the approach still count. Problems you copied do not.

## 4 · Interview drill (3 min)

<details>
<summary><strong>Q1. A method has two nested loops, the inner one running from 0 to i. What is the time complexity?</strong></summary>

Still O(n²). The inner loop runs 1 + 2 + ... + n = n(n+1)/2 times, and the n²/2 term dominates. Constants and lower-order terms drop out of Big-O.
</details>

<details>
<summary><strong>Q2. What is the difference between an array and an `ArrayList` in Java?</strong></summary>

An array is fixed-size, holds primitives or objects, and is accessed with `[]`. `ArrayList` is a resizable list backed by an array, holds objects only (so `int` becomes `Integer`), and grows by about 50 percent when full, which costs an occasional O(n) copy but keeps appends amortised O(1).
</details>

<details>
<summary><strong>Q3. Why does a bank interviewer start with a pattern or array problem instead of a hard one?</strong></summary>

To see how you communicate and structure a loop under mild pressure. They are checking for off-by-one errors, whether you state the approach before typing, and whether you test with a small input. Nailing the easy problem cleanly earns more trust than fumbling a hard one.
</details>
